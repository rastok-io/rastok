# The M0.5 slice — engine consolidation

> Implementation slice — non-normative. Opened 2026-08-05, target end
> of August 2026. M0.5 widens nothing: it consolidates what
> [M0 proved](m0-exit-report.md) so the next milestone builds on a
> separable core, a sealed artifact, and a spec-complete identity.

## Scope, in order

The order is load-bearing: the delivery-reference specification
(item 2) freezes the journal/OUTBOUND vocabulary that the core split
and the plan blob then rely on. No runtime code for items 3–5 starts
before item 2 lands.

1. **M0 exit report** — done: [`m0-exit-report.md`](m0-exit-report.md).
2. **DeliveryRef → `call_ref` specification** — spec-first
   ([delivery-semantics](../spec/delivery-semantics.md),
   [identity §3](../spec/identity.md)/OUTBOUND): formalize the
   delivery reference, seal it in the OUTBOUND record, derive
   `call_ref` from it. Never by salting `request_digest`, whose
   definition — the exact sent bytes — must not move. Closes the
   multiport prerequisite of [`m0-exit-notes.md`](m0-exit-notes.md).
3. **The `rastok-core` split** — a no_std-ready kernel (`core` +
   `alloc`): node, envelope, values, plan, the step machinery, the
   `Journal`/`Partner` trait seams. Zero connectors in the kernel —
   even `Process` is std-layer. Six atomic commits: import
   normalization (mechanical no-op under std); clippy frontier guards
   (disallowed types and methods, explicit allows in the std layer);
   `PreparedRequest` moved into the boundary vocabulary — the one
   semantic commit of the lot, adjacent to item 2 so `vm.rs` is
   touched once; the crate move behind re-exports (zero churn for
   callers); the `#![no_std]` gate with `blake3` sans default
   features; the CI frontier job.
4. **Plan-blob** — the sealed serialization of the `ExecutionPlan`,
   format specified in an architecture note BEFORE any byte is
   written, under the same canonical-CBOR discipline as the golden
   traces (one byte discipline in the repository): magic, format
   version, semantic hash, canonical body, blake3 seal. Unknown
   version or broken seal is a typed refusal, never a silent
   migration. Decoder in `rastok-core` (the embedded entry), encoder
   in the std layer. Frozen only after item 2.
5. **no_std spike on target** (RP2350) — time-boxed, go/no-go
   criteria written before the first measurement, verdict recorded as
   a dated architecture note whatever the outcome. A GO leaves the
   option dormant; a NO-GO documents the exact cause.
6. **Connector conformance harness** — the ten contract cases of
   [stdlib.md §1](../spec/stdlib.md) as reusable fixtures over the
   `boundary::Partner` seam. Goal: a new connector lands in half a
   day. The same seam is the future portability contract between the
   std and embedded worlds.
7. **LLM-authorship benchmark, wave 1** — ~20 tasks, several models,
   versioned prompts; the loop generate → check → diagnostics →
   retry → simulate, measured.

## Minimal evidence

- the exit report and this slice referenced from `ROADMAP.md`;
- the delivery-reference rules landed in the specification corpus
  with their identity pins updated;
- `cargo check -p rastok-core --target thumbv8m.main-none-eabihf`
  green in CI — the frontier is mechanical, not reviewed;
- the whole M0 gate green throughout, with **byte-identical semantic
  hash and golden seals before and after the split** — the move is a
  proven-neutral refactoring, by construction;
- a plan-blob round-trip (compile → encode → decode → re-hash) with
  the identical hash, a blessed blob fixture for the example, and
  typed refusals for a bumped version and a corrupted byte;
- the spike verdict note, dated, with its numbers;
- one existing connector re-expressed on the harness, and the
  harness's fixture set runnable against any `Partner`;
- the benchmark's task list, prompts, and first measurements
  recorded (strategy-side objectives own the metrics).

## Explicit non-goals

No new language surface, no new connectors, no multiport execution
(item 2 specifies; M1 implements), no scheduler changes, no
distribution. Anything in
[`parallelism-notes.md`](parallelism-notes.md) stays a decision list.
