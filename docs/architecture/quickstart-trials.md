# Opening quickstart — two unaided trials

Status: protocol prepared; **neither external trial has been performed**.
An agent's successful test commands do not replace these trials. Yoann selects
two people who have not developed Rastok and provides the tagged preview site
and release binary. No invitation or result is implied by this document.

## Freeze the material

Record the source commit/tag, website revision, binary target and SHA-256,
OS version, and whether the person already has Rust. Both people read the same
`docs/site/getting-started.md` as rendered by the preview site. The README's copied
block remains covered by `site_content`.

The observer may recover a broken recording tool, but cannot explain Rastok,
suggest commands, or point out a control. If help is needed, stop that attempt
and record the exact difficulty before giving it. Record permission to retain
screenshots; use tester A/B in the public summary rather than personal names.

## Observe, do not coach

Start timing when the person opens the quickstart. Record elapsed time at:

1. Installation complete; the documented binary or source fallback runs.
2. `rastok new hello` creates a source file and the Lab reaches its expected
   result. Record any error or command guessed outside the page.
3. The flagship opens paused, the person advances it and locates a timeout,
   delayed retry and final output in the debugger.
4. The person makes the chapter's documented break-it edit, reads the golden
   divergence, and explains which fact changed without being coached.

Ask afterwards: what did Replay do, what did the mailbox number count, and
what did `202` promise? Record the answers, not a retroactive correction of
the observed attempt. Report confusion and failed steps alongside timings.
