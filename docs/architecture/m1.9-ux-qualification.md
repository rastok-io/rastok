# M1.9 — browser UX refinement, 2026-09-07

Scope: the visual simulation debugger after v16, not the semantic core.
The controller and presentation must expose the same boundaries regardless
of playback cadence or time spent inspecting a paused frame.
Post-audit presentation corrections and final requalification: 2026-09-08.

## Reproduced defects and corrections

- A late historical response could overwrite Return live (B32 returned to B31).
  Presentation requests now have cancellation generations; the latest user
  intent wins without mutating the retained timeline.
- Pause during a buffered frame request still presented that frame (B0 → B1).
  Pause invalidates both the timer and any already requested presentation.
  Live refreshes are serialized; command completion also refreshes explicitly.
- Keyboard selection rebuilt the graph and lost focus. A surviving node,
  instance badge or mailbox now keeps focus, without forcing Definition.
- Narrow layout hid Return live and the session selector. Both remain visible;
  the scenario and legend wrap without page-width overflow.
- The scenario panel showed an action outline instead of source. It now uses
  an identity-neutral compiler side table with exact DSL and next-action lines.
  Classified programs suppress raw scenario source before JSON construction;
  focused sensitive/personal tests prevent a second disclosure path.
- Polling mock outcomes while already paused could advance a boundary without
  a command, or overwrite an action's frame. Paused simulation no longer polls
  spontaneously. A Step discovering quiescence proceeds to the next authored
  action rather than requiring a second empty click. The reference tour now
  visits every B0–B32 once and agrees with Continue on the complete history.
- The queue legend no longer describes removed dotted control edges; it names
  current `≡` mailbox occupancy and `⧉` opened instances. Speed labels fit.
- Fable's independent pass reproduced empty-canvas deselection, stale replay
  messages, shifting/clipped transport buttons and the misleading empty
  Envelope label. These now have browser regressions and local fixes. Engine
  status is separate from the fixed-width view-state label; Step over explains
  why the current action must first finish.

## Repeatable browser qualification

Build the optional UI and run the existing geometry tests:

```sh
cargo build -p rastok --features hosted-ui
node --test crates/rastok/src/ui/graph_layout.test.cjs
```

`crates/rastok/src/ui/browser.test.cjs` is an optional real-browser suite. It
starts its own loopback UI processes and isolated browser contexts and closes
them afterwards. It requires an explicitly installed Playwright and Chrome;
neither is added to the page, Cargo dependencies or normal workspace gate.

```sh
RASTOK_PLAYWRIGHT=/absolute/path/to/installed/playwright \
RASTOK_CHROME=/absolute/path/to/chrome \
RASTOK_UI_CAPTURES=/absolute/path/to/evidence \
node --test crates/rastok/src/ui/browser.test.cjs
```

The ten browser tests cover delayed-response races, keyboard focus, narrow
history, authored DSL, Reset/session isolation, every manual boundary, the
complete Step/Continue history comparison, mailbox/instance tabs, zoom,
keyboard splitter operation, both playback speeds, canvas deselection, stable
transport controls, history-status cleanup and light/dark screenshots. Browser exceptions
fail the tests. The real server CSP is retained, not disabled for automation.
SSE remains open during the tests; network-idle is not a completion signal.

Reference-host result: **10/10 browser tests and 13/13 geometry tests pass**.
The visible-page cadence test measures median intervals of 1,002 ms at one
event/s and 252 ms at four events/s. These are presentation intervals, not
logical execution time; background-tab scheduling remains browser-controlled.
Captures: B0, B1, B8, B32 and completed History at 1352×760; historical view at
700×760; light historical view at 1352×760. These are mechanical browser
evidence, not a substitute for independent usability judgment.

The final sequential workspace gate passes **1,263 tests, zero failures and
zero ignored tests**; fmt, all-target/all-feature clippy with warnings denied,
and workspace documentation also pass. The semantic core, plan and goldens
are unchanged. The embedded spike and protocol interop probes were not rerun
for this hosted-only UX patch.

The in-app browser controller still fails during bootstrap due to its missing
browser-service path. Qualification used the already installed standalone
Playwright with isolated headless Chrome instead. The independent
[Fable Chrome audit](m1.9-fable-ux-audit.md) is complete and retained separately.
Its open stepping and readability findings remain named; M1.9 is not declared
closed by this report.
