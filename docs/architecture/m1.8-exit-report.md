# M1.8 exit report — data policy, secrets, observations and exact cost

> Closed 2026-08-31. Normative authorities:
> [D-2026-08-30-1 through D-2026-08-30-6 and D-2026-08-31-1](../spec/decisions.md).
> Ordered implementation record:
> [`m1.8-observability-backlog.md`](m1.8-observability-backlog.md).

## Verdict

M1.8 closes one policy and accounting foundation without adding a second
ledger. A logical schema may carry a sparse canonical side-table for
`@sensitive`, `@secret`, `@personal`, `@measure` and `@cost`; the table changes
policy, not `DataType` assignability. The compiler derives effective policy,
categorical validation proves it again, and runtime boundaries consume the
verdict rather than reconstructing it.

Secrets cross only as logical references into declared Driver settings.
Personal data is admitted only under a complete immutable run-scoped privacy
attestation. Every causal record can be queried as one typed structural
observation, while optional JSON logging consumes disposable bounded copies.
Exact measures and money are folded lazily from the journal and validated
schemas into one public `CostReport`; exporter state is never an accounting
authority.

The optional hosted OpenTelemetry transport is deliberately not claimed. Its
A6 qualification found that M1.8 owns no exact commit instant or duration, so
constructing spans would invent time. The typed observation seam remains; A6
resumes only when those temporal facts are retained exactly and an independent
Collector test can be supplied.

```text
source schema + sparse annotations
               │
               ▼
       checked effective policy ──▶ v15 + Registry-free proof
               │
               ├──▶ deployment boundary ──▶ SecretRef / privacy attestation
               │
causal journal ├──▶ typed RecordObservation ──▶ bounded JSON projection
               │
               └──▶ lazy AccountingObservation ──▶ exact CostReport
```

## A0–A3 — one closed annotation model

Source annotation arguments are named plan constants. Unknown identities,
duplicates, dynamic arguments, illegal carriers and paths that do not resolve
in the adjacent type refuse through one exact-path diagnostic family. Aliases
expand onto structural paths for fields, collections and both union families.

Categorical v15 transports sparse tables beside every schema owner: raw and
resolved ports, nested Graph ports, owner values, state cells and handler
bindings. Decode resolves every path and independently rechecks annotation
membership, carrier, currency, local declarations and effective resolved
policy. Sabotage cannot erase, forge, reorder or detach a table from its type.

One Registry-free fixed point follows edges, exact projections, calculations,
guards, state and Loop recurrence. Alternative accounting producers must agree
exactly. Control dependence carries security/privacy taint; opaque guest work
cannot execute around the conservative policy. An entirely unannotated plan
takes the direct validation and transaction paths without an operation walk.

## A3.1–A4 — GDPR-facing policy and the secret boundary

`@personal` covers personal data broadly rather than treating PII as the whole
legal category. Its `special`, `criminal` and `identifier` flags represent the
distinct Article 9, Article 10 and data-subject-indexing facts. The deployment
profile supplies processing activity, purpose/legal-basis references,
recipients, transfer safeguards and run-scoped retention. Rastok verifies
coverage and redacts; it does not claim to replace the controller's legal or
organisational judgement.

The hosted profile parses as a closed JSON object outside `rastok-core`.
`env("NAME")` and `secret("logical/path")` lower into typed boot references;
the core receives typed bindings only. M1 opens precisely HttpClient `url` for
environment values and `auth_bearer` for secret references. The real and Lab
Drivers bind the same logical prepared request, while only the real boundary
may overlay credential bytes after the causal OUTBOUND open. Missing,
mis-versioned, unauthorized and unused bindings refuse before execution.

An unused alias may describe `@secret`, but every use at an executable schema
owner refuses at source check because no field-level externalization protocol
exists yet. Categorical validation and VM boot retain a forged-package belt.
Personal data may use only the run-scoped in-memory
journal; durable clear retention remains closed until an erasure or
externalization capability is proved.

## A5 — retained observations and disposable logs

`RecordObservation` names an exact structural transition and correlation
derivable from causal history: origin, owner/instance, Connector and typed
Call or Session/write identity when present. It carries no Host, Worker,
thread, socket, wall time or invented duration. `MemJournal` reconstructs the
stream lazily, so the default commit path owns no duplicate observation store.

`rastok run --json-logs` projects optional copies over a bounded `try_send`
channel. Full or disconnected output increments a saturating local drop
counter, advances the disposable cursor and never blocks or fails execution.
Payload is absent by default; an explicit projection applies schema-aware
redaction before JSON construction. Saturation and exporter failure leave
journal records and reports identical.

## A7 — exact per-flow accounting

`AccountingObservation` adds an envelope id, canonical field paths, exact
samples and a complete flow scope to the structural observation. The scope
keeps origin, instance generation, owner, current Node, port, exchange,
nearest causal Connector and optional deployment provider/model separately.
For a dynamic Connector output typed by a downstream decoder, attribution
walks the sealed envelope-parent lineage to the actual Connector producer; it
never guesses from topology or a name, and never consults a record later than
the observation being folded.

`CostReport::from_journal` reconstructs those observations from immutable
records and independently validated schemas. A supplied `CostProfile` must
match the stable reference/digest in the run header, and typed observations
cannot be repriced under different provider/model dimensions. Omitting a
profile preserves usage and yields explicit positive `unpriced` remainders.
An annotated calculated-cost field additionally requires a profile row for
its sealed causal Connector; an unrelated profile is not evidence.

The measure registry fixes carrier, exact unit and inclusion. Cache-read and
cache-creation tokens are subsets of inclusive input tokens; reasoning tokens
are a subset of output tokens. A specialized rule carves out only its share;
otherwise the parent price covers it. Contradictions refuse instead of
underflowing, being hidden by later samples or double-counting.

`Money` is the canonical struct convention backed by `decimal(38,18)` and an
ISO currency, not a new logical type. Pricing uses checked normalized decimal
arithmetic and power-of-ten bundles. Any overflow, rounding need, malformed
currency or domain escape refuses. Provider-reported and
pricebook-calculated basis, currency, priced measure and profile evidence are
separate grouping dimensions; no cross-currency total exists.

## Portability, interoperability and resource evidence

`rastok-core --no-default-features` compiles for all three established 32-bit
targets:

- `thumbv8m.main-none-eabihf` (Cortex-M33);
- `thumbv7m-none-eabi` (Cortex-M3 without FPU);
- `riscv32imac-unknown-none-elf` (generic non-Arm baseline).

The independent probes were rerun on 2026-08-31. HTTP prints
`CADDY_HTTP1_CLIENT_OK`, `NGINX_HTTP1_CLIENT_OK`,
`CURL_HTTP1_SERVER_OK` and `NGHTTP2_SERVER_OK`. WebSocket prints
`NODE_WS_OK` and `H2_EXTENDED_CONNECT_OK`. Open external release
qualifications remain visible in
[`release-qualification.md`](release-qualification.md).

The Cortex-M33 QEMU image prints `SPIKE_OK`, the unchanged v15 package/hash
and 67 records. It measures 17,844 decode ticks; 2,713 average / 2,622 minimum /
2,966 maximum relay ticks; and a 129,972-byte true heap high-water mark.
Linked `.text + .rodata` is 729,156 B (712.1 KiB). The maximum is about
148.3k calibrated instructions, retaining a 1.011× margin under the
pre-recorded 150k bound. Heap has the narrower resource margin: 1,100 bytes,
0.84%, or 1.008× below the 128 KiB ceiling. The next change touching the
embedded path must re-measure that heap bound before making another acceptance
claim. A7–A8 and the source-check-only review correction add no accounting
work to this unannotated relay path.

The adversarial correction was re-measured before this report was amended.
The M33 output reproduces A8 exactly: 17,844 decode ticks, 2,713 / 2,622 /

## Named limits

- Hosted OpenTelemetry export waits for exact retained commit time/duration,
  a dependency/binary audit and an independent Collector transcript.
- There is no Budget aspect, quota, reservation or pre-effect refusal in M1.8.
- There is no FX, billing authority, FOCUS-conformance, OpenCost allocation,
  sampled calibration or automatic model selection claim.
- User-defined measures/dimensions and final Rastok operational instrument
  names wait for their retained facts and exporter.
- Raw secret-bearing envelopes, field-level secret externalization, hot
  rotation and encrypted durable-journal storage remain closed.
- An annotation and privacy profile provide technical controls, not a legal
  compliance certificate; durable personal-data retention waits for proved
  erasure/externalization.
- The core parses no hosted configuration format and links no exporter,
  secret-store, cloud-price or financial dependency.
- The then-unnamed live-view item must consume this public report rather than
  create another accounting fold. It was subsequently specified and delivered
  as M1.9 `--ui`.
