# M1.4 exit report — logical instances and lifetime

> Evidence record — non-normative. M1.4 ran through the ordered R0–R7
> gates in [`m1.4-instances-backlog.md`](m1.4-instances-backlog.md). The
> semantic authority is [`instances.md`](../spec/instances.md) and the settled
> decision is D-2026-08-18-1.

## Verdict

The executable M1.4 instance slice exits. Source-owned `instances.key`, the
five independent lifetime profiles, hierarchical Graph/Node addresses,
Node-private state, bounded Closing, successor generations, nested Graphs,
and bounded instance-local joins all pass through source, checker, categorical
plan-package v9, Registry-free validation, the one-worker VM, the public Lab,
and canonical trace projection.

The proof is deliberately about **logical execution**, not an invented
cluster runtime. M1 remains synchronous, single-process and one-worker. A
future Coordinator owns only the physical lookup from a stable virtual shard
to its current Worker; that lookup is absent from semantic hashes, instance
addresses, journal records and replay input.

| Claim | Executable evidence |

| Producer-selected routing | Ingress and emissions prepare the complete owner chain, reserve mailbox room, then commit the route and producer fact atomically. Failed keys or bindings consume no sequence, cursor, state or effect. |

| Closing loses no call terminal | R5 race probes cover drain, canonical cancellation, observed exits, `OutcomeUnknown`, late replies, residual deliveries, inner-first Graph closure and successor backpressure. |
| Joins add no key authority | R6 correlates only inside the owning Operator instance; declared-order/FIFO selection, `where`, `within`, `last`, `JoinExpired`, metadata presence and independent lazy payloads are tested. |
| Physical placement is non-causal | R7 maps one public keyed address to a fixed virtual shard, moves that shard from `(host-a, worker-1)` to `(host-b, worker-7)`, and proves the semantic hash, journal records, canonical record bytes and reconstructed replay trace remain equal. |
| Portability remains real | The final gate builds `rastok-core` without `std` for Cortex-M33, Cortex-M3 and RV32IMAC, then executes the v9 package and relay under emulated Cortex-M33. |

## Negative-space audit

- No executable `PartitionSpec`, `PartitionKey`, v8 body, `partition_key`, or
  `target_partition` type remains.
- `partition`, every former `per` spelling, join `by`, and targeted `stop`
  survive only as recovery syntax named `Removed*`; each source form produces
  exactly one `E-INSTANCE` migration diagnostic and cannot enter HIR or plan.
- Package versions 2–8 are categorically refused. V8 is not migrated or
  normalized into v9.
- The measured unkeyed routing fast path is retained because R4 showed that
  rebuilding the same address on every relay breaks the embedded relay bound.
  It is not a singleton semantic authority: it returns a complete canonical
  `InstanceRef`; a two-delivery executable probe independently reconstructs
  the exact address of an unkeyed child below a keyed Graph and exercises the
  second-route lookup. The general address path remains authoritative for
  missing, closing and successor generations.
- R7 also strengthens Graph drain evidence: an already-admitted reply reaches
  an existing **keyed** descendant during Closing, rather than being routed to
  its successor generation.

## Deliberate identity moves

M1.4 kept package, semantic and causal identity as three separate ledgers:

| Gate | Deliberate move | Explicit non-move |
|---|---|---|
| R0–R1 | New source using the new instance semantics gains its declared HIR extension. The unpublished old source has no compatibility identity. | Existing programs and goldens do not move. |
| R2 | Categorical v9 adds the root/owner table and scoped edges to every package; echo, gauge, JSONL and the embedded spike package move. | Existing semantic hashes and causal traces remain byte-identical. |
| R3 | The four causal traces gain complete route/firing/cursor references; the review correction then seals owner paths as segment arrays and deliberately re-blesses those same four traces once. | Semantic hashes and `.rkp` bodies do not move. |
| R4 | Universal lazy owner lifecycle adds `l:start`/`l:stop` facts to the same four causal traces. | Semantic hashes and `.rkp` bodies do not move. |
| R5 | Empty `OutcomeUnknown` extends `ProcessExit`; Process hashes/packages move to compiler probe `29c69b70…`, JSONL `a058f1aa…`, and echo/spike `419a52a1…`. | Connector-free gauge remains `0d3ad43d…`; existing non-closing traces do not move. |
| R6–R7 | Newly executable nested Graph/join programs have their own identity, but no existing artifact is reinterpreted. | Existing hashes, packages and causal traces remain byte-identical. |

R7 does re-bless the non-semantic `minimal.ast` debug projection: the
recovery-only field is printed as `removed_per` instead of `per`. This is the
negative-space proof made visible, not a program, package, or causal-identity
move.

The intermediate v8 container was an unreleased draft, explicitly
superseded and refused. It is recorded in history, not counted as a target
format or a compatibility move.

## Named limits — not claimed by this exit

The following remain explicit gates rather than silent approximations:

- source production of non-plan owner `val`s and dynamic Connector settings;
- source/lowering of Graph lifecycle handlers (Graph lifecycle facts already
  execute); full crash boot reconstruction through the future `RecoveryFold`;
- sliding/event-time windows, cross-instance joins, targeted stop and shared
  mutable Graph state;
- physical shard leases, Worker fencing, migration, distributed journal
  serialization and M:N scheduling.

Those limits do not weaken the M1.4 claim: every construct admitted by the
current checker executes with the declared instance semantics, and every
future construct above still refuses by name or has no public spelling.

## Final gate

The final gate passes 697 all-feature tests, warning-free fmt/clippy/doc, and
`rastok-core` `no_std` builds for Cortex-M33, Cortex-M3, and RV32IMAC. The
emulated Cortex-M33 v9 package returns `SPIKE_OK`: 16 865 decode ticks, 2 753
relay ticks on average / 2 986 maximum, a 106 788-byte heap watermark, and
526 416 bytes of `.text + .rodata`. Full measurement context lives in
[`spike-rp2350-emulated.md`](spike-rp2350-emulated.md). No R7 semantic hash,
package or causal golden trace was re-blessed.
