# M1.7 — the `Loop` NodeAspect

> Ordered implementation backlog, normalized 2026-08-28. A recognized source
> spelling is not an executable Loop: every gate remains fail-closed until its
> plan, Registry-free validation and runtime evidence have landed together.

**Current checkpoint:** L0 and the normative L1 contract are landed. The
source half of L2 already reduces positive `Loop.fuel` and the two closed
`Loop.delay` forms into recovery HIR, with exact migration diagnostics, but
lowering still refuses every aspect. No Loop port, plan byte, journal fact or
runtime behavior is claimed yet.

## Exit statement

M1.7 proves that Rastok can express finite temporal recursion while its
spatial topology remains a DAG:

- `Loop` is a Graph aspect, never a NodeType, Connector policy or hidden edge;
- `in`, `next`, `out`, `expired` form one typed boundary contract;
- every iteration proves exactly one control decision, `next XOR out`;
- every admitted run has a termination witness (`fuel` now, a checked
  `measure` later) and every body application is individually terminating;
- every re-entry is a committed `l:next` fact in the same instance generation;
- one root envelope owns one independent `LoopRunRef`, fuel and wakeup;
- delay uses the generic dated-event queue and Lab virtual time;
- recovery reconstructs runs from the journal and Closing cannot revive a
  stale wakeup;
- non-Loop programs pay no semantic/runtime tax beyond the categorical format
  move explicitly attributed to aspect transport.

## Architecture

```text
Graph : Loop
  ├── ordinary finite spatial DAG
  ├── boundary: in / next / out / expired
  └── LoopSpec: fuel + delay + optional proof certificate
                         │
root envelope ──▶ LoopRunRef + journal fold
                         │
                  one Graph traversal
                    ├── out ─────▶ terminal
                    └── next ────▶ l:next ───▶ same run, same generation
                                  (immediate or dated)
```

There is no Loop ledger beside the journal and no RAM-only attempt authority.

## Ordered gates

### L0 — Normalize Node taxonomy and instance spelling

- Publish closed `node::{Kind, Type, Aspect}`.
- Keep `plan::NodeExecution` for the existing Operator/Connector execution
  payload; do not overload it with semantic classification.
- Make Graph/Operator types implicit, exact Connector types mandatory and
  `App` root-only.
- Recognize `Loop`/`Saga`, reject bad order/duplicates/incompatibility, but
  keep aspects fail-closed.
- Replace unpublished `instances = { key = ... }` with singular `instance`.
- Reconcile all normative docs without changing v12 plans or identities.

**Exit:** taxonomy tests and migration diagnostics pass; plan/package/causal
goldens are byte-identical.

### L1 — Freeze the Loop protocol

- Freeze Graph-only v1, the four port roles and `LoopExpired { last_state }`.
- Freeze `Loop.fuel`, `Loop.delay`, theorem-tier `Loop.invariant` /
  `Loop.measure`, reserved `Loop.jitter`, and removal diagnostics for the old
  `variant/backoff/until/limit` family.
- Freeze per-root `LoopRunRef`, iteration ordinal, same-generation recurrence,
  exact fuel boundary and causal-parent recipe.
- State body totality, Connector timeout, Process multi-output and instance
  Closing constraints explicitly.
- Record the theorem obligations and proof-certificate boundary without
  claiming a solver.

**Exit:** Whitepaper, specs, examples and this backlog describe one protocol;
the checker still refuses it by name.

### L2 — Carry one categorical `LoopSpec`

- Parse/check qualified Loop attributes on Graphs only.
- Contribute `next: In` and `expired: LoopExpired<In>` to the checked Graph
  boundary; reject collisions and spatial wiring of `next`.
- Lift Graph lifecycle/body handlers needed by the aspect rather than adding a
  second Loop-only AST.
- Add the closed aspect list and `LoopSpec` to the next categorical plan
  version. Serialize only canonical plan constants and checked expression /
  certificate trees.
- Re-derive carrier, ports, types, fuel, delay, totality prerequisites and
  canonical aspect order Registry-free after decode.
- Enumerate semantic/package moves before re-blessing; keep the connector-free
  gauge as scope witness.

**Exit:** source→HIR→plan→round-trip works for a valid fuel-only Loop; forged,
partial or theorem-only plans refuse before VM construction.

### L3 — Prove one total control decision

- Build a finite control-flow summary of the flattened Graph boundary.
- Prove every reachable completed traversal emits exactly one of `next` and
  `out`; other outputs do not decide.
- Reject missing, double, ambiguous, multi-frame and open-ended paths with
  path-specific diagnostics.
- Treat Connector results as fresh typed symbolic values; use explicit guards
  only. Require finite Call timeout / guest budget and reject Event/Session
  waits in v1.
- Repeat the decision check at runtime only as validation defense.

**Exit:** accepted plans cannot reach a runtime “which branch won?” choice;
negative tests cover zero, both, repeated and Connector-cardinality cases.

### L4 — Make fuel and `l:next` a journal fold

- Allocate extend-only identities for `LoopRunRef`, open/progress/close facts
  and the `l:next` payload before writing records.
- Derive a run from the external root envelope and keep multiple runs in one
  instance independent.
- Apply the exact fuel recursion: the last allowed `next` becomes
  `LoopExpired { last_state = proposed_next }` without committing `l:next`.
- Commit immediate re-entry with the `next` emission as parent, same
  `InstanceRef`, next iteration ordinal and remaining fuel.
- Rebuild all live run state by folding records; reject double-open,
  skipped/duplicated iteration, wrong parent and post-close progress.

**Exit:** countdown and finite fold scenarios execute without a spatial
back-edge; crash/replay cannot regain fuel or duplicate an iteration.

### L5 — Date re-entry and compose with instance lifecycle

- Implement fixed and exponential `Loop.delay` with safe ceiling saturation.
- Use timer kind 5 and the generic dated-event queue in production and Lab.
- Count a wakeup as an armed idle obligation; generation-fence it at Closing.
- Model-check completion/arm/fire/duplicate/stale/Closing interleavings and
  equal-date deterministic order.
- Prove delay affects neither Call timeout nor instance lifetime.

**Exit:** real-shaped and Lab execution produce the same causal core, and no
stale wakeup can enter a successor generation.

### L6 — Add the first theorem checker

- Define a small proof-certificate algebra in `rastok-core` with a `no_std`,
  deterministic verifier.
- Add hosted symbolic SSA/dataflow over affine integer arithmetic,
  comparisons, booleans, structs and tagged unions.
- Check invariant entry/preservation, total decision and strict measure
  decrease on every `next` path.
- Use summaries for nested pure Graphs; reject unsupported guest, state and
  Connector progress claims instead of trusting them.
- Admit `measure` without fuel only after the certificate independently proves
  well-founded termination. Keep `fuel + measure` as proof plus cap.
- Add an optional Rocq/Coq export/oracle without making it a runtime
  dependency.

**Exit:** a decreasing countdown works without fuel; a non-decreasing,
path-dependent or opaque proof fails closed for the stated obligation.

### L7 — Close M1.7

- Remove only the deferrals whose complete gates landed; direct
  Operator/Connector Loop, jitter and unsupported theorem fragments retain
  named owners.
- Exercise keyed and singleton instances, concurrent runs, nested Graphs,
  expiry/Closing, Connector retry and Process multi-frame refusal through
  public Lab scenarios.
- Audit package, semantic and causal identity separately.
- Run all-feature fmt/clippy/test/doc, three `no_std` ISA builds, independent
  interop unaffected checks and the Cortex-M33 spike.
- Update roadmap, Whitepaper, contribution map and release qualification from
  executable facts only; record binary/hot-path deltas against pre-written
  bounds.

**Exit:** every current Loop claim is executable or named as a later gate, and
the milestone report is reproducible without private VM inspection.

## Named limits

- Direct `Operator + Loop` and `ConnectorType + Loop` wait for a demonstrated
  need; wrapping either in a Graph is the v1 spelling.
- General recursion and unbounded `while` are not topology features.
- Custom well-founded relations, lexicographic measures and user-defined
  aspects are later theorem/extension work.
- Jitter remains reserved until its deterministic `(LoopRunRef, iteration)`
  recipe and distribution are frozen.
- `Saga + Loop` remains fail-closed until Saga execution defines and tests the
  composition order.
- Multi-Worker placement consumes the same logical run/address facts but is
  outside the one-worker M1 runtime.
